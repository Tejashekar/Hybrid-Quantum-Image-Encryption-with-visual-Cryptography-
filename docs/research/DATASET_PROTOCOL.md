# Dataset integrity and preprocessing protocol

## Dataset inventory

The current real-image source directory is `experiments/real-input-7`. It contains **7 image files** but only **5 unique decoded image contents**. Image files are not independent samples: the corrected experiment processes each decoded content once. The final independent sample count for this repository dataset is therefore **5**, which is a small dataset and does not support broad statistical generalization by itself.

Decoded pixels are read with OpenCV `IMREAD_UNCHANGED`. Duplicate detection hashes the decoded array's dtype, shape (including channel count), and C-order pixel bytes with SHA-256. This detects byte-identical decoded arrays regardless of filename or encoded-file metadata. The generated inventory is [phase5-center-crop-v1.json](../../experiments/manifests/phase5-center-crop-v1.json).

## Preprocessing version `center-square-crop-resize-grayscale-v1`

The research protocol intentionally uses grayscale `uint8` plaintext. Color sources are decoded in OpenCV BGR/BGRA order and converted to grayscale after resizing; 2D grayscale sources remain grayscale. Processing is deterministic for the same decoded array, target size, and OpenCV implementation.

For source width `w` and height `h`, preprocessing takes the largest centered square with side `s=min(w,h)`, using `left=(w-s)//2` and `top=(h-s)//2`. It then resizes that square to 128×128 with OpenCV `INTER_AREA` interpolation and converts color output to grayscale `uint8`. The implementation supports other square target sizes for explicitly configured small experiments; the main image workflow uses 128×128.

This replaces the previous direct stretch resize. Center cropping discards pixels outside the central square, and resizing changes spatial resolution. Therefore **“Encryption/decryption is lossless with respect to the preprocessed plaintext representation.”** It does not reconstruct the full-resolution source file.

## Experiment input handling and result preservation

For `--image-dir`, the runner groups inputs by decoded-content hash and processes one canonical filename per unique content. Rows retain the canonical filename, all filename aliases, source content hash, original dimensions/channels, and preprocessing version/parameters. A, B, C, D, and E labels and all supported E threshold labels remain unchanged.

The corrected runner defaults to `experiments/results/phase5-center-crop-v1`. Existing result JSON/CSV files are not overwritten unless `--overwrite` is explicitly supplied. The prior result archives remain historical; they were produced with the older preprocessing and are not regenerated by this correction.

Example corrected run:

```powershell
.venv\Scripts\python.exe -m experiments.run_experiments --image-dir experiments/real-input-7 --size 128 --seed 20261001
```
